# Hotel Management API

This is an Backend Project Focused on Hotel Management. The main purpose of this project is to give an simple clean API for Hotel staff members.

### Flow of API

Following is the standard Flow of this project.
-User Registers
-User Sees all rooms available and on which date.
-User book an room.
-Manager/staff member are ables to track the booking , Manage the Users and Customers alerting when rooms are available.
